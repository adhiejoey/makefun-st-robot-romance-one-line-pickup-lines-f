One flirtatious line aimed at a machine that runs on attention: it turns the
transformer's attention mechanism into a very human problem — ever since
meeting this particular AI, the speaker simply cannot focus on anyone else.

## How it works

`main.ts` (Node 22, standard library only, no network) writes the single
pickup line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), checking
first that it sits inside the 1–200 character gate.
